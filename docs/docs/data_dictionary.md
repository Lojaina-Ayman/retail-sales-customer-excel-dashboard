# Data Dictionary

| Field Name | Data Type | Description |
| :--- | :--- | :--- |
| `Order ID` | Text | Unique identifier assigned to each sales transaction |
| `Order Date` | Date | Date the order was placed by the customer |
| `Ship Date` | Date | Date the items were dispatched |
| `Customer ID` | Text | Unique identifier for the purchasing client |
| `State` | Text | Geographic location of the transaction |
| `Region` | Text | High-level territory: West, East, Central, South |
| `Sub-Category` | Text | Specific product grouping (e.g., Binders, Paper, Phones) |
| `Sales` | Decimal | Total gross revenue generated |
| `Profit` | Decimal | Net profit or loss recorded |
